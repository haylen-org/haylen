# 📋 Reference

The reference lists the manifests of Haylen and its command line: every key of `haylen.json` and `plugin.json`, every field of `haylen-sdk.json` and every command of `haylen`. The guides explain what each one is for and link here, and the [Lua API](../lua-api/README.md) has a reference of its own.

## Pages

| Name | Description | Link |
| --- | --- | --- |
| Commands | Every command of `haylen` with its arguments, options, defaults and the result it prints as JSON. | [`commands.md`](commands.md) |
| `haylen.json` | Every key of the manifest of an app with its type, default and meaning, the sections of the generated projects, the entries of plugins and the errors of every value that the engine refuses. | [`haylen-json.md`](haylen-json.md) |
| `haylen-sdk.json` | Every field of the manifest of an engine SDK: its port, the version and revision of the engine, its configuration, its slices and its host tools. | [`haylen-sdk-json.md`](haylen-sdk-json.md) |
| `plugin.json` | Every key of the manifest of a native plugin, its parameters, its placeholders and every type of contribution with its fields and how it merges. | [`plugin-json.md`](plugin-json.md) |
